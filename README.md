# ProntoTix Android

Proyecto Android válido creado con:

- Kotlin
- Jetpack Compose
- Material 3
- Gradle Kotlin DSL

## Cómo abrirlo

1. Descomprime el ZIP.
2. En Android Studio selecciona **Open**.
3. Selecciona la carpeta `ProntoTixAndroid`.
4. Espera a que termine **Gradle Sync**.
5. Usa **Build > Make Project**.

La primera compilación puede descargar dependencias de Gradle.
